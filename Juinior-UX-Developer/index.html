How I work

A simple process from problem to usable product.

I keep the process practical. Understand the user, make the flow clear, test it, then refine the interface with development in mind.

01

Understand

I start with user needs, business requirements and the main task the experience needs to support.

02

Map

I use user flows and journeys to make the path through the product clear before designing screens.

03

Wireframe

I explore layout and information hierarchy at low fidelity so changes are quick and easy.

04

Prototype

I move into Figma prototypes and high-fidelity UI using reusable components and variants.

05

Test

I use interviews, surveys, feedback and usability testing to find friction and improve the flow.

06

Build and refine

I work closely with implementation, check responsive behaviour and improve details after testing.
